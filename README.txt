BLACK WOLF — மறைக்கப்பட்ட பேரரசன்
Starter website files

FILES
- index.html: site structure and starter Tamil reading sample
- styles.css: responsive modern colourful design
- script.js: mobile menu, episode search/filter, sample reader dialog

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser. Internet is only needed for the optional Google Fonts; the rest is local.

HOW TO PUBLISH FOR FREE (GitHub Pages)
1. Sign in or create an account at https://github.com/
2. Create a new PUBLIC repository, for example: black-wolf-story
3. Upload index.html, styles.css, and script.js to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. The public URL will appear in the Pages section.

ALTERNATIVE
You can upload the same three files to a static hosting service such as Netlify Drop. Follow that provider's current upload/publish instructions.

IMPORTANT
- This ZIP is a ready-to-publish static starter, but it is NOT yet live on the internet.
- No login, database, comments, admin panel, or cloud episode editor is included.
- Episode 1 is a short sample written for this demo. Episodes 2 and 3 are placeholders.
- Replace placeholder text and add only story content you have rights to publish.
- A custom domain is optional and usually costs money. Free hosting providers may offer a free subdomain.
